GORNJA SIGA STATUS STRATEGY 2026–2030 — INTERACTIVE EDITION

Files
-----
1. Gornja_Siga_Status_Strategy_Interactive_2026-2030.html
2. Gornja_Siga_Status_Strategy_2026-2030.pdf

How to use
----------
Open the HTML file in Chrome, Edge, Firefox, or Safari.

The HTML file itself contains:
- the interactive overview;
- all 14 strategic pillars;
- all 40 actions in the Strategic Action Plan;
- the 2026–2030 implementation timeline;
- the full risk matrix;
- measurable indicators of success;
- a searchable, page-by-page text extraction of the complete 24-page strategy;
- a learning/quiz section.

The PDF is included so users can also open the original formatted strategy.

Sharing
-------
You may send the ZIP package by email, Proton Mail, WeTransfer, cloud storage, USB, or place the files on a website.

Important
---------
The interactive checklist state is local to each browser session. It does not automatically synchronize between different users.
The embedded strategy text and interactive features work without an internet connection.
